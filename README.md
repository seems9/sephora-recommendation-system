# sephora-recommendation-system

Sephora Product Insights & Recommendation System
A comprehensive analysis of Sephora's skincare and beauty products using machine learning and data visualization techniques.

📌 Project Overview
This project leverages customer reviews and product data to:

Explore trends in Sephora product ratings, prices, and categories.

Recommend similar products based on text descriptions using NLP.

Predict user ratings using regression models and neural networks.

🔗 Dataset: Sephora Products & Skincare Reviews - Kaggle

🛠 Features
📊 Exploratory Data Analysis (EDA):

Bar plots, scatter plots, and hexbin visualizations of product metrics.

🧠 Recommendation System:

Content-based recommendations using TF-IDF and cosine similarity.

📈 Rating Prediction Models:

Linear Regression

Random Forest Regressor

Neural Network (TensorFlow/K
